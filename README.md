# My Commit Repo Branches

## Жобаның мақсаты
Бұл жоба Git жүйесінде тармақтармен жұмыс істеуді үйренуге арналған.

## Әзірлеу ортасын баптау
1. Git бағдарламасын орнату.
2. VS Code бағдарламасын ашу.
3. Жобаның репозиторийін ашу.
4. Git командалары арқылы тармақтармен жұмыс істеу.

## Қосымша нұсқаулық
Жоба Git Branching нұсқаулығына сәйкес орындалады.
